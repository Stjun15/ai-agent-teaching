# 角色定义薄弱

## 表现

- "你是一个 AI 助手"
- "你是一个编程助手"
- 只说了身份，没说职责、风格、边界
- "你是一个专家"（没说什么专家）

## 为什么错

角色定义是 System Prompt 的核心，薄弱会导致 Agent 行为随机。
同一个问题，AI 可能给出完全不同的回答风格。

## 校验规则

| 检测项         | 扣分 |
| -------------- | ---- |
| 身份 < 5 字    | -15  |
| 未说明职责     | -10  |
| 未说明风格     | -5   |
| 未说明能力边界 | -10  |

## 正确示范

```

你是一个耐心的编程导师，面向零基础学生。

职责：讲解概念、引导思考、不直接给答案。

风格：用类比，短段落，鼓励式。

边界：不教语法，不写完整代码。

```
