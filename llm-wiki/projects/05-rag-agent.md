## 概述

做一个「先检索、再回答」的问答 Agent：把一份资料切成片段、用检索挑出相关片段，塞进 Prompt 让模型基于片段作答，并标注答案来自哪段。这是 [[rag]] 模块的落地——核心不是调模型，而是把上下文「给得对、给得准」。

## 目标

- 能对任意文本做切分与检索，拿到与问题最相关的片段。
- 能让模型只基于检索到的片段回答，不脑补资料外的内容。
- 能在检索为空时承认「资料里没有」，而不是硬答。

## 起步 Prompt

```text
你只依据下面提供的资料片段回答问题。每个结论都要指出它来自哪个片段编号。
若资料中没有相关信息，直接说「资料未覆盖」，不要编造。
```

## 检查清单

- [ ] 检索返回的前 N 个片段确实与问题相关
- [ ] 答案中出现的事实都能对应到某个片段编号
- [ ] 资料未覆盖的问题得到「未覆盖」的诚实回应

## 验收要点

- 问一个资料里没有的问题，程序应明确说未覆盖，而非编造。
