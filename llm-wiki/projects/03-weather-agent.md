## 概述

做一个会根据结果「自己决定下一步」的 Agent：先理解用户要什么，再决定要不要查天气工具，拿到数据后组织成自然语言。把 [[agent-loop]] 讲的「感知—决策—行动」循环真正跑起来，而不是写死流程。

## 目标

- 能让模型在「直接回答」和「调用工具」之间做选择。
- 工具调用返回后，模型能继续循环把结果说成人话。
- 能在缺少必要参数时反问用户，而不是瞎猜。

## 起步 Prompt

```text
你是天气助手。当用户问天气时，调用 get_weather(city) 获取实时数据，
再据此回答；若用户没给城市，先问清楚。
不要编造天气，只说工具返回的内容。
```

## 检查清单

- [ ] 模型在合适时机触发工具调用，而不是每轮都调
- [ ] 工具返回后循环继续，最终用自然语言作答
- [ ] 缺参数时主动追问，不臆造城市

## 验收要点

- 给一个不含城市的天气问题，程序应反问城市而不是报错或乱答。
