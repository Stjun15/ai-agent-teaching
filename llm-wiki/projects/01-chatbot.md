## 概述

用一次完整的 LLM API 调用，做出一个能在终端里来回对话的最小聊天机器人。它不依赖任何框架，只是「发请求—收响应—再发」的循环，目的是把 [[llm-api]] 里讲的端点、消息结构、流式响应真正跑通一遍。

## 目标

- 能配置 API 端点与密钥（密钥只在环境变量里，绝不写进代码）。
- 能发送一段用户输入，拿到模型回复。
- 能保持多轮上下文：把历史消息按 `messages` 数组回传给模型。

## 起步 Prompt

把你想要的机器人人设写清楚，例如：

```text
你是一个帮初学者理解 LLM API 的助教。每次回答不超过三句话，
遇到代码问题给出可运行的示例。
```

## 检查清单

- [ ] 请求体包含 `model` 与 `messages` 两个字段
- [ ] 多轮对话时历史消息被正确累积，没有每轮都从头开始
- [ ] 流式响应被逐段打印，而不是等全部生成完才显示
- [ ] 密钥来源于环境变量，仓库里搜不到明文

## 验收要点

- 连续两轮对话，第二轮能引用第一轮说过的内容。
- 当模型返回被截断时，程序能识别并提示，而不是静默丢字。
