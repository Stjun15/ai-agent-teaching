# Agent Loop 测验

## 选择题

**1.** Agent 循环里「停止条件」应该：

- A. 由模型自己决定，代码不干预
- B. 在写循环体之前先写，至少包含达成、上限、异常三类
- C. 只设轮次上限就够
- D. 等到真的卡住了再加

答案：B。见 [[stop-condition]]。模型不主动说「我做完了」，出口必须由代码给出。

**2.** 循环跑到轮次上限被迫退出时，正确的做法是：

- A. 静默返回已有内容
- B. 报告「卡住了」，并说明卡在第几步
- C. 把上限调大继续跑
- D. 清空历史重新开始

答案：B。静默退出会让用户以为回答本来就这么短。

## 填空题

**3.** Agent 循环每一轮的输入是：上一轮的 ______ 加上工具执行结果。

答案：消息（messages）。循环靠累积消息推进，不是靠变量。

## 简答题

**4.** 为什么「工具解析失败就重试」是危险的？

评分要点：失败原因可能是输入本身有问题，重试只会重复烧 token；应该用计数与上限把失败变成可报告的边界，而不是无限重试。

## 判分要点

- 选择题解析由题库给出（客观题判分走规则，不调模型）；
- 简答题答不出「成本 / 无法收敛」任一层判不通过。
