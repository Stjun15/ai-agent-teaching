# MCP 测验

## 选择题

**1.** 想让 Agent「不要用某个工具」，可靠的做法是：

- A. 在提示词里写「不要使用 XX 工具」
- B. 注册时就不把它放进白名单
- C. 给它一个空实现
- D. 每次调用后检查并回滚

答案：B。提示词是请求不是约束，工具注册了就可能被调用，见 [[least-privilege-tools]]。

**2.** MCP 与「自己写几个函数」的主要区别是：

- A. MCP 更快
- B. MCP 是协议：工具能力可以被外部进程提供、跨应用复用
- C. MCP 不需要 Schema
- D. MCP 只能本地使用

答案：B。

## 填空题

**3.** 危险能力（写文件、发请求、执行命令）默认应该 ______ 白名单。

答案：不进（排除在）。

## 简答题

**4.** 为什么「先全部注册、再靠提示词限制」是不安全的？

评分要点：注入内容可能诱导模型调用任何已注册工具；约束必须发生在注册阶段（代码层），提示词层面的劝阻在诱导下会失效。

## 判分要点

- 只答「提示词可能被忽略」不够，要答出「约束必须在代码层/注册阶段」；
- 客观题解析来自题库，主观题由点评 Agent 打分。
