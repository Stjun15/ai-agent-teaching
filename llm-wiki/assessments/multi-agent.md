# 多 Agent 测验

## 选择题

**1.** 两个 Agent 都能写同一份答案时，最大的问题是：

- A. 速度慢
- B. 不知道谁该负责，同一输入可能有时对有时错
- C. token 消耗翻倍
- D. 需要更多提示词

答案：B。责任不清是协作的主要故障模式，见 [[single-writer]]。

**2.** 评审者 Agent 的正确产出是：

- A. 改好的最终答案
- B. 「同意 / 反对 + 理由」，不直接改
- C. 一个新的任务分解
- D. 一段总结

答案：B。评审者没有写权限，这一点要写进它的 System Prompt。

## 填空题

**3.** 多 Agent 协作里，把责任压到一个角色上的模式叫 ______。

答案：单一出口。

## 简答题

**4.** 评审者只输出「很好，没问题」，这说明什么？

评分要点：它不是评审者而是复读机；有效评审必须给出可判定的理由（改哪里、为什么），否则这轮协作没有产生信息。

## 判分要点

- 答成「说明答案真的没问题」判不通过 —— 无理由的同意不构成评审；
- 客观题走规则判分，主观题由点评 Agent 打分。
