# 工具调用测验

## 选择题

**1.** 模型选工具时看到的是：

- A. 函数的源码
- B. 函数的 JSON Schema（名字、描述、参数）
- C. 函数的单元测试
- D. 函数的注释

答案：B。Schema 里没说清的字段，模型只能猜，见 [[schema-first-tool]]。

**2.** 工具抛异常时，Agent 应该：

- A. 把堆栈原文当作工具结果继续推理
- B. 捕获并转成结构化错误信息回给模型
- C. 直接终止整个会话
- D. 忽略，当作没调用过

答案：B。A 会让模型对着堆栈编故事，C/D 丢掉了可恢复的机会。

## 填空题

**3.** 工具命名用动宾结构，例如获取天气应命名为 ______。

答案：`get_weather`。模型靠名字选工具，`weather` 这种名词看不出动作。

## 简答题

**4.** 给「查询某城市天气」写一个参数的 description，要求让模型不会填错。

评分要点：说清不填会怎样（默认行为）、边界值（城市名用中文还是英文、是否含国家）、格式示例。三者答全为通过。

## 判分要点

- 只写「城市名」三个字的 description 判不通过 —— 模型无法判断格式；
- 主观题由点评 Agent 打分，点评失败（兜底）不计入掌握度。
