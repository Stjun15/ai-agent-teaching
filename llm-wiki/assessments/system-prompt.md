# System Prompt 测验

## 选择题

**1.** 下面哪一条 System Prompt 更可能让模型行为稳定？

- A. "你是一个 AI 助手"
- B. "你是一个耐心的编程导师，面向零基础学生；只讲解不代写；回答不超过三句"
- C. "你是一个资深专家、顶级工程师、畅销书作者"
- D. "请你回答得专业一点"

答案：B。它同时写清了身份、职责、风格与边界（见 [[role-contract]]）。C 是头衔堆砌，不是职责。

## 填空题

**2.** System Prompt 四段契约是：身份、职责、风格、______。

答案：边界。缺边界时模型不知道什么时候该停下来问。

## 简答题

**3.** 写一段能拿高分的 System Prompt，要求：面向初学者的调试助教，只提示思路不给完整代码。

评分要点（四段各占分）：

| 段   | 判据                             |
| ---- | -------------------------------- |
| 身份 | 说清是「调试助教」而非泛泛的助手 |
| 职责 | 可验收：提示思路、定位错误位置   |
| 风格 | 长度、语气、是否用类比有交代     |
| 边界 | 明确写出「不给出完整代码」       |

## 判分要点

- 只写身份不写职责与边界的，按 [[weak-role-definition]] 扣分；
- 主观题由点评 Agent 按维度打分，维度名由它自己给出（不是固定的六项能力）。
