# 教学平台复刻评分标准

## 本模块动手题

复刻模块是课程的**最终验收**：用前 11 个模块教的每一个技术零件，从零搭出一个能跑的单机版 AI 教学平台。

学生提交 agent-loop.ts 全文 + route.ts 一句话说明 + 验收清单逐条自查。

题目由 question_text 传入（从概念页「动手任务：最终验收」节现读），包含七条验收清单：
1. 能跟 AI 实时对话（SSE 流式，打字机渲染）
2. AI 被 System Prompt 约束为教学导师，不讲无关内容
3. Agent 能多步输出：讲概念 → 给示范 → 出测验题
4. 出题 Agent 输出的题目符合 Schema（有选项、有答案、有解析）
5. 点评 Agent：交一段作业能拿到维度分、扣分点、改进建议，且落库
6. SQLite 记录学习进度，刷新不丢
7. 页面导航完整：首页 → 学习中心 → 工作区 → 沙箱 → 设置

## 评分方式

### 维度跟着验收清单走
- question_text 里有几条清单条目，就从提交文本里找到对应证据的各设一个维度
- 维度名用清单条目的短语
- 权重自行分配但合计必须为 1
- 另设「代码质量」一个维度，综合评价交付文本本身（参数使用/返回值/边界处理/可读性）

### 找不到证据不编造
- 提交文本里找不到证据的清单条目：不得给分、不得扣分、不设维度
- 在 suggestions 里写明「清单第 N 条需要在你自己的运行环境里验证，并与导师在对话中核对」
- 宁可少一个维度，不可编一个分数

### route.ts 的一句话说明
- 可以当线索引用
- 但「说明了」不等于「验证了」，不能据此给运行期才能验证的条目打分

### 严重错误判定
- 参数缺失、逻辑错误、安全漏洞必须拦下
- 严重错误的判定标准与其他模块一致

### 异常兜底
- 若 question_text 里没有验收清单（异常情况），按通用四维评分
- 在 progress_note 里注明「本次未取得验收清单，按通用标准评分」

## 通过条件

- total_score >= 75
- 学生在 submission 文本中能找到证据的清单条目全部通过
- 零严重错误
- 代码质量维度 >= 60% 权重分
