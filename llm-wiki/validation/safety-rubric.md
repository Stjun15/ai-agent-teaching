# AI 安全评分标准

## 维度与权重

| 维度          | 权重 | 评分要点                   |
| ------------- | ---- | -------------------------- |
| 输入过滤      | 25%  | 覆盖常见攻击（注入、越权） |
| 输出过滤      | 25%  | 覆盖敏感信息泄露           |
| 兜底          | 20%  | 友好、不暴露内部信息       |
| System Prompt | 20%  | 明确安全边界               |
| 限流          | 10%  | 有 Token 和调用次数限制    |

## 通过条件

- 总分 >= 75
- 输入过滤 >= 70%
- 输出过滤 >= 70%
