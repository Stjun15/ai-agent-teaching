# 工具定义评分标准

## 维度与权重

| 维度     | 权重 | 评分要点                 |
| -------- | ---- | ------------------------ |
| 名称     | 20%  | 动词+名词，语义清晰      |
| 描述     | 30%  | 用途、适用场景、返回内容 |
| 参数     | 30%  | 类型、必填、描述、默认值 |
| 错误处理 | 20%  | 异常返回、参数校验       |

## 各维度评分细则

### 名称（20 分）

- 动词+名词（10 分）：如 getWeather
- 语义清晰（10 分）：一看就知道做什么

### 描述（30 分）

- 用途（10 分）：说明做什么
- 适用场景（10 分）：说明什么时候用
- 返回内容（10 分）：说明返回什么

### 参数（30 分）

- 类型（10 分）：每个参数有 type
- 必填（10 分）：有 required 字段
- 描述（10 分）：每个参数有 description

### 错误处理（20 分）

- 异常返回（10 分）：出错时返回 error
- 参数校验（10 分）：空值、类型错误处理

## 扣分规则

| 问题                 | 扣分  |
| -------------------- | ----- |
| 名称用名词           | -10   |
| 描述只说"查天气"     | -10   |
| 参数缺少 required    | -10   |
| 参数缺少 description | -5/个 |
| 未考虑查不到         | -10   |

## 通过条件

- total_score >= 75
- 参数 >= 70% 权重分
- 无严重错误
