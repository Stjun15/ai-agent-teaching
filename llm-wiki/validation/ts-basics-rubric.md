# TypeScript 基础评分标准

## 本模块动手题

学生需要解释 TypeScript 的基础概念（类型标注、接口、泛型等），
用"给变量贴标签"的类比向完全不懂编程的朋友讲清楚。

## 正确答案要点

1. 用自己的话解释"类型标注"是什么——不是复制定义，是理解和转述
2. 用类比（贴标签/说明书/分类标签）说明类型的用途
3. 举一个生活中的例子（如"鸡蛋的保质期标签"）

## 维度与权重

| 维度       | 权重 | 评分要点                                           |
| ---------- | ---- | -------------------------------------------------- |
| 理解准确度 | 40%  | 类型标注的核心概念理解正确，没有事实性错误           |
| 表达清晰度 | 30%  | 用自己的话讲清楚，有类比、有生活例子                 |
| 完整覆盖   | 30%  | 覆盖了"是什么""为什么""怎么用"三个层面               |

## 扣分规则

| 问题                     | 扣分  |
| ------------------------ | ----- |
| 把类型标注说成强制约束而非描述     | -20   |
| 混淆类型标注和变量声明           | -15   |
| 没有用自己的例子             | -10   |
| 直接复制原文无自己的理解       | -10   |
| 表述混乱、逻辑断裂            | -10   |
| 只答了部分问题               | -15   |

## 通过条件

- total_score >= 75
- 理解准确度 >= 60% 权重分
- 无严重错误
