# 工具调用评分标准

## 本模块动手题

1. 用"遥控器"的例子解释什么是工具调用
2. 设计一个"查快递"的工具：名字、描述、参数
3. 回答：两次调用不同单号结果会不会一样？实现里要注意什么？

## 正确答案要点

### 概念解释
- 遥控器比喻：每个按钮 = 一个工具，AI 按按钮 → 执行 → 看结果
- Agent Loop 的 Act 步就是调工具

### 工具定义
- 名字：动词+名词（如 query_express）
- 描述：说清用途和适用场景（不能只说"查快递"）
- 参数：tracking_number（string，必填）

### 后续问题
- 结果不一样（不同单号 = 不同包裹 = 不同物流状态）
- 注意事项：参数空不瞎编、查不到说清楚、工具不记状态

## 维度与权重

| 维度     | 权重 | 评分要点                             |
| -------- | ---- | ------------------------------------ |
| 工具定义 | 40%  | 名字/描述/参数三项都正确              |
| 概念理解 | 25%  | 比喻恰当、解释了工具调用的本质        |
| 边界思考 | 20%  | 能说出工具实现的注意事项              |
| 完整覆盖 | 15%  | 三问都答了                           |

## 扣分规则

| 问题                     | 扣分  |
| ------------------------ | ----- |
| 工具名是名词不是动词          | -10   |
| 描述只说"查快递"没说细节      | -15   |
| 参数缺少 required            | -10   |
| 说结果一样（理解错误）        | -15   |
| 没说工具不能记状态            | -5    |
| 比喻不恰当                   | -10   |

## 通过条件

- total_score >= 75
- 工具定义 >= 60% 权重分
- 名字必须是动词+名词
