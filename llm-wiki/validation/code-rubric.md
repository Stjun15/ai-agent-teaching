# 核心代码评分标准

## 维度与权重

| 维度     | 权重 | 评分要点           |
| -------- | ---- | ------------------ |
| 参数使用 | 30%  | 正确解构、类型匹配 |
| 返回值   | 30%  | 结构正确、字段完整 |
| 边界处理 | 20%  | 空值、异常、超时   |
| 可读性   | 20%  | 命名、注释、简洁   |

## 扣分规则

| 问题           | 扣分 |
| -------------- | ---- |
| 参数解构错误   | -20  |
| 返回值缺失字段 | -15  |
| 未处理空值     | -10  |
| 未处理异常     | -10  |
| 命名不清晰     | -5   |

## 通过条件

- total_score >= 75
- is_correct = true
- 无严重错误

## 通过后

返回 `{ "is_correct": true, "next_action": "visualize" }`，触发可视化场景。
