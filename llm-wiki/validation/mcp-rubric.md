# MCP 评分标准

## 维度与权重

| 维度          | 权重 | 评分要点                   |
| ------------- | ---- | -------------------------- |
| 工具选择      | 25%  | 选对工具、用途匹配         |
| 工具描述      | 25%  | 准确描述用途和场景         |
| System Prompt | 30%  | 说明何时调用、怎么处理结果 |
| 错误处理      | 10%  | 工具失败怎么办             |
| 简洁性        | 10%  | 无冗余                     |

## 通过条件

- 总分 >= 75
- System Prompt >= 70%
- 工具描述 >= 70%
