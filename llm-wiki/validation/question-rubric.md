# 出题评分标准

## 维度与权重

| 维度     | 权重 | 评分要点       |
| -------- | ---- | -------------- |
| 针对性   | 30%  | 针对学生薄弱点 |
| 场景化   | 25%  | 真实场景       |
| 难度递进 | 20%  | 基础→应用→综合 |
| 不重复   | 15%  | 不与题库重复   |
| 提示分级 | 10%  | 有 hint_levels |

## 通过条件

- 总分 >= 75
- 针对性 >= 70%
- 无重复题
