# Agent Loop 评分标准

## 本模块动手题

1. 用"做菜"的例子，给完全没学过编程的朋友解释 Agent Loop 的四步
2. 回答：如果 Agent 调了工具但不去观察（Observe）返回结果，会发生什么？举一个具体例子。

## 正确答案要点

### 四步解释
- Think（看菜谱/想做什么）→ Act（动手做/调工具）→ Observe（尝味道/看结果）→ Repeat（不够就回去）
- 必须用做菜例子，不能用编程术语替代
- 每步都要讲清楚"在做什么"+"为什么这一步不能跳过"

### Observe 缺失后果
- 举具体例子（如查天气 API 返回错误但 Agent 不看）
- 核心：不观察 = 闭着眼睛做事，错了也不知道
- 必须说明后果（如编了假答案、用户被误导）

## 维度与权重

| 维度       | 权重 | 评分要点                             |
| ---------- | ---- | ------------------------------------ |
| 理解准确度 | 40%  | 四步各自的作用理解正确               |
| 类比恰当   | 30%  | 做菜比喻贯穿、步骤对应准确           |
| 完整覆盖   | 30%  | 四步都讲到了 + 第二个问题有具体例子  |

## 扣分规则

| 问题                     | 扣分  |
| ------------------------ | ----- |
| 把 Loop 说成死循环       | -20   |
| 跳过了 Observe 的解释   | -15   |
| 没用做菜的比喻          | -10   |
| Observe 缺失后果太笼统（如"会出错"） | -10   |
| 没举具体例子             | -10   |
| 四步少了一步             | -15   |

## 通过条件

- total_score >= 75
- 理解准确度 >= 60% 权重分
- 四步全部覆盖
