# 问答解释评分标准

Q&A 类模块（ts-basics、agent-loop、ai-safety）的动手环节是**纯文本解释**任务
（读代码标注、比喻解释概念、类比说明原理），不涉及写代码/Prompt/工具定义。
本评分标准专注评价文本回答的**理解质量**与**表达能力**。

## 维度与权重

| 维度       | 权重 | 评分要点                                           |
| ---------- | ---- | -------------------------------------------------- |
| 理解准确度 | 40%  | 核心概念/代码含义理解正确，没有事实性错误           |
| 表达清晰度 | 30%  | 用自己的话讲清楚，条理分明，不用套话               |
| 完整覆盖   | 30%  | 回答了作业要求的所有问题/覆盖了所有要解释的点       |

## 各维度评分细则

### 理解准确度（40 分）

- 核心判断正确（20 分）：关键结论与教学定义一致
- 无事实性错误（10 分）：不张冠李戴、不混淆概念
- 举例恰当（10 分）：如用自己的例子说明，例子的逻辑是正确的

### 表达清晰度（30 分）

- 用自己的话（10 分）：不是复制粘贴原文或背诵
- 条理分明（10 分）：先总后分、因果关系清楚
- 易懂（10 分）：目标读者（完全不懂编程的朋友）能看懂

### 完整覆盖（30 分）

- 回答了核心问题（15 分）：作业标题问什么就答了什么
- 没有漏要点（15 分）：多项子问题时每项都有回应

## 扣分规则

| 问题                     | 扣分  |
| ------------------------ | ----- |
| 概念理解明显错误         | -20   |
| 把 A 概念说成 B 概念     | -15   |
| 举例中的逻辑错误         | -10   |
| 直接复制原文无自己的理解 | -10   |
| 表述混乱、逻辑断裂       | -10   |
| 没有用自己的话说         | -5    |
| 只答了部分问题           | -15   |
| 漏了明显要点             | -10   |
| 空泛无内容               | -30   |

## 评分等级

| 分数   | 等级   | 说明                 |
| ------ | ------ | -------------------- |
| 90-100 | 优秀   | 理解准确，表达清晰   |
| 75-89  | 良好   | 大体正确，少量改进   |
| 60-74  | 及格   | 有理解偏差需修正     |
| <60    | 不及格 | 概念理解错误，需重学 |

## 通过条件

- total_score >= 75
- 理解准确度 >= 60% 权重分
- 无严重错误（"概念理解明显错误" 与 "把 A 概念说成 B 概念" 为严重错误）
