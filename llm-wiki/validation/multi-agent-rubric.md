# 多 Agent 评分标准

## 维度与权重

| 维度          | 权重 | 评分要点               |
| ------------- | ---- | ---------------------- |
| 角色分工      | 30%  | 职责清晰、不重叠       |
| System Prompt | 25%  | 每个角色定义准确       |
| 协作流程      | 25%  | 顺序合理、信息传递清楚 |
| 冲突处理      | 10%  | 有兜底机制             |
| 简洁性        | 10%  | 无冗余角色             |

## 通过条件

- 总分 >= 75
- 角色分工 >= 70%
- 协作流程 >= 70%
