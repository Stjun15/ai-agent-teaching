# Wiki 页面评分标准

## 维度与权重

| 维度     | 权重 | 评分要点         |
| -------- | ---- | ---------------- |
| 页面类型 | 15%  | 类型正确         |
| 前置概念 | 20%  | 依赖关系合理     |
| 定义     | 25%  | 清晰、准确       |
| 关键点   | 25%  | 覆盖核心、有结构 |
| 常见误解 | 15%  | 真实、有教学价值 |

## 通过条件

- 总分 >= 75
- 定义 >= 70%
- 关键点 >= 70%
