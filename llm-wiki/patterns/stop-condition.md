# 显式停止条件

## 什么时候用

写 Agent 循环（模型 → 工具 → 再问模型 → …）的时候。**在写循环体之前先写停止条件**。

## 写法

三类停止条件，至少各写一条：

```text
1. 达成：拿到所需信息 / 工具返回成功 → 退出
2. 上限：轮次 >= N 或 token 预算用尽 → 强制退出并回报
3. 异常：工具连续失败 / 模型输出解析不了 → 退出，不要重试到天亮
```

配套的循环体：

```text
while 未触发任何停止条件:
    问模型 → 解析 → 若调用工具则执行 → 把结果拼回消息
退出时输出「为什么停」：达成 / 到上限 / 出错
```

## 为什么有效

Agent 循环和 `for` 循环不一样：它的「条件」藏在模型的输出里，模型不主动说「我做完了」，循环就不知道该停。没有显式上限时，一个解析失败会让循环反复重试 —— 每一次重试都在烧 token，而界面上只看到它一直在转。

上限不是保守，是**让失败有边界**：轮次用完就报告「卡住了，卡在第几步」，比无限转圈有用。

## 容易退化成什么

- 退化成 [[infinite-loop]]：只写 `while true`，唯一出口是模型某次恰好不再调工具；
- 退化成静默打满：设了上限但退出时不说原因，用户只看到回答突然结束了。
