# 先引用后作答

## 什么时候用

让模型基于检索到的资料回答问题时。**先取出带出处的片段，再让模型照着答**，并且要求它回答里带出处。

## 写法

```text
1. 检索：拿到 N 个片段，每个片段记住「来自哪一页」
2. 排序截断：按相关度取前 K，K 小一点（3~5 就够）
3. 组装：把片段连同出处一起放进上下文
4. 要求：回答里每条结论后面跟出处；没有依据就说「资料里没有」
```

## 为什么有效

两个理由，都跟「可复核」有关：

1. **出处让答案能被检查**。学生能点开原文看模型是不是在编 —— 没有出处时，一串流畅的错误结论和正确答案长得一模一样。
2. **「资料里没有」是一句合法回答**。允许模型说不知道，它才不会用参数里的记忆去补洞。

反过来，把整批资料全塞进去（over-retrieval）会稀释掉关键片段：上下文越长，中间部分的注意力越弱，真正有用的那一段反而被淹掉。

## 容易退化成什么

- 退化成 [[over-retrieval]]：一次检索 20 段全塞，成本上去了、答案质量下来了；
- 退化成假引用：出处是模型编的 —— 出处必须由检索层给定，不能让模型自己填。
