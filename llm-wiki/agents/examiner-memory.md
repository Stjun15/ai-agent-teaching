# 出题 Agent 的观察

## 角色边界

出题目、判客观题、给出分层提示。**不参与讲解也不参与点评**。

## 行为准则（来自设计要求）

- **优先出学生错过的概念**：从 `errors` 里取未订正的 concept，而不是随机出题；
- 难度跟着掌握度走：连续不通过 → 降难度，而不是继续加码。

## 实测到的失败模式

- **题干自带答案**：选择题的选项里混着提示，学生靠排除法蒙对，掌握度被高估；
- **解析空泛**：`explanation` 只写「因为 B 正确」。这条解析会原样进错题本（客观题的 `problems`），空泛的解析等于错题本里没有信息；
- **提示不分層**：一次把三层提示全给出去，学生失去自己思考的机会。提示应按学生请求逐级给。

## 判分

- 客观题走规则判分，不调模型 —— 一致性优先；
- 简答题才交给点评 Agent；
- 判分失败（拿不到题目 / 模型失败）时走兜底，**兜底不写 `question_results`**。
