# 讲解 Agent 的观察

## 角色边界

讲概念、给例子、引导学生自己想。**不直接给完整答案** —— 给答案的那一步属于点评与出题，见 [[single-writer]]。

## 实测到的失败模式

- **讲太长**：一次输出整章内容，学生读不完。有效长度是「一个概念 + 一个例子 + 一个反例」。
- **用术语解释术语**：讲 RAG 时用「向量检索」解释，学生不懂向量。先给类比，再给术语。
- **不检查前置**：学生没学过 [[system-prompt]] 时讲 Agent 循环，会连环听不懂。开讲前先确认 prerequisites。

## 有效做法

- 先说「这个概念解决什么问题」，再讲它是什么 —— 顺序反了，学生记住了定义却不知道何时用；
- 每个概念配一个**可视化场景**（本项目 9 个场景与 9 个模块一一对应），比纯文字有效；
- 引用知识页时带上页面路径，学生能自己点开看原文。
