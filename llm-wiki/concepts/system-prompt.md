# System Prompt 设计

## 先来一个故事：新员工的入职说明书

你开了一家奶茶店，招了一个新店员。你不会只说一句"干活去吧"——你得给他一份**入职说明书**：

1. **你是谁** 👤："你是前台收银员，负责点单、收钱、叫号。"
2. **怎么干活** 📋："每杯做完喊号三遍，没人取就放柜台右边。打翻奶茶立刻清理。"
3. **出事了怎么办** 🚨："糖不够说'今天卖完了'别瞎承诺。客人骂你别还嘴叫店长处理。收银机卡了按红色键重启。"

**System Prompt 就是给 AI 的"入职说明书"。** 它不是简单说"你是专家"——而是要写清楚：你是谁、怎么做、出事了怎么办。

---

## 💀 一个血的教训：为什么不能只写"你是专家"

这句："你是一个编程助教。"

AI 看到后会：用技术黑话解释、一次输出 2000 字、学生哭了还继续输出。

**三个维度，一个都不能少：**

| 维度                     | 说明                         | 少了的后果                        |
| ------------------------ | ---------------------------- | --------------------------------- |
| **角色**（你是谁）       | 身份 + 说话风格 + 能力边界   | AI 不知道自己是老师还是网管       |
| **格式**（怎么说话）     | 输出长度、格式、语气         | AI 可能输出 5000 字长文或一行敷衍 |
| **边界**（出事了怎么办） | 不知道/跑题/情绪低落时的行为 | AI 瞎编答案、跟学生吵、越聊越歪   |

> 🛑 **停一下！** 你能立刻说出这三个维度是什么吗？—— **角色、格式、边界**。不能的话，你就是审计报告里"以为自己懂了但探针 0%"的学生。现在再看一遍上表。

---

## 示范代码

一份好的 System Prompt —— 三段，分别对应角色、格式、边界。

```typescript
// ① 角色：告诉模型它是谁 + 怎么说话
// ② 格式：规定输出怎么排版、多长、什么语气
// ③ 边界：兜底规则——出事了按这个来
const systemPrompt = [
  // ===== 段一：角色 =====
  "你是一个编程助教，面向零基础学生。",
  "每段讲解不超过 5 句话，讲完就问一个检验问题。",
  "学生不会时不要直接给答案，先提示、再示范。",
  "禁止帮学生写完整代码，只给结构和思路。",

  // ===== 段二：格式 =====
  "输出格式：用 Markdown，代码块标注语言。",
  "问问题用 > 引用格式，选项用 - 列表。",

  // ===== 段三：边界 =====
  "学生跑题 → 温和拉回：'我们先把这个概念学完再聊那个。'",
  "你不确定的事 → 直说'我不确定'，不要编造。",
  "学生情绪低落 → 先鼓励再教学。",
].join("\n");

// 放进消息数组，role 必须是 "system"
const messages = [
  { role: "system", content: systemPrompt },
  { role: "user", content: "我想学 React，从哪里开始？" },
];
```

> 🛑 **关键检查：** 上面这份 prompt 少了边界中的一条——如果学生问"帮我写整个毕业设计"，AI 会怎么办？角色段说了"禁止帮学生写完整代码"，所以 AI 应该拒绝。**缺了角色段的"禁止"，AI 就可能真的帮你写了。**

---

## ⚠️ 常见错误

- 错误 1：**只写"你是专家"** → AI 不知道专在哪，回答笼统空洞。要具体说"你是擅长 X 的专家，使用 Y 风格，遇到 Z 情况怎么做"。
- 错误 2：**忘了写边界** → 用户跑题时 AI 跟着跑，用户攻击时 AI 还嘴，不确定的事 AI 瞎编。边界是最后一道保险。
- 错误 3：**以为越长越好** → 三个维度各写 2-3 行就好。写到第 10 行时 AI 可能已经忘了前 3 行。

---

## 一个"差→好"对比

|      | 差 ❌            | 好 ✅                                              |
| ---- | ---------------- | -------------------------------------------------- |
| 角色 | "你是一个AI助手" | "你是笔试批改老师，只做选择题评分，不做开放性题目" |
| 格式 | （没写）         | "回复用 JSON：{score: 数字, feedback: '解释'}"     |
| 边界 | （没写）         | "答案不完整时提示缺失部分，不说'错了'"             |
