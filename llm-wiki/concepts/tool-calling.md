# 工具调用

## 先来一个故事：遥控器和电视

你手里有一个遥控器。按"音量+"，电视声音变大。按"换台"，电视换频道。

**遥控器上的每个按钮，就是一个"工具"。**

- 遥控器不会自己变音量——它在等**你按按钮**
- 你按了按钮 → 遥控器发信号 → 电视执行
- 你不会去手动调电视旋钮（太麻烦）——遥控器帮你"调用"电视的功能

**Agent 的工具调用，就是给 AI 一个"遥控器"：** AI 说"我要查天气"，你就给它注册一个 `getWeather` 按钮；AI 按了这个按钮（调用工具），你帮它执行，然后把结果告诉它。AI 不会自己上网查天气——它必须通过你给它的"按钮"来做事。

💡 **核心认知：** AI 本身只能"说话"，不能"做事"。你给它注册什么工具，它才能调用什么工具。工具 = AI 的"手和脚"。

---

## 为什么需要工具？（没工具的 AI 有多瞎）

> **回顾上节：** Agent Loop 的四步是 Think → Act → Observe → Repeat。其中 **Act 就是"调工具"**——但上一讲我们把它当成黑箱，只写了 `act(decision)`。这一讲，**我们把 Act 打开**：工具是怎么定义的？怎么注册到 Agent 身上的？Agent 怎么决定用哪个工具？

**场景对比：**

| 没工具时 😫                        | 有工具时 😎                                     |
| ---------------------------------- | ----------------------------------------------- |
| 你问"北京今天多少度？"             | 你问"北京今天多少度？"                          |
| AI 瞎编："大概 25 度吧"（幻觉）    | AI 调 `getWeather` → 拿到真实数据 → "25 度，晴" |
| 你问"3 斤苹果每斤 5 块，一共？"    | 你问"3 斤苹果每斤 5 块，一共？"                 |
| AI 心算："嗯…大概 13 块？"（算错） | AI 调 `calculate` → 程序精确算 → "15 块"        |

工具让 AI 从"只会说"升级成"能做事"。做对一件事的价值，远大于说对一万句话。

## 关键步骤：三步给 AI 装上一个工具

不需要懂 JSON Schema。你就告诉 AI 三件事：

> 本节的 `###` 子节是**这一讲必须掌握的步骤清单**，讲稿应当逐步覆盖。
> 结构与 `platform-replica.md` 一致，便于自动检测「讲稿漏讲了哪一步」。

### 第一步 · 给工具起个名字

👈 动词+名词，如 `getWeather`、`calculate`

- 坏名字：`weather`（太模糊，是查？还是改？还是删？）
- 好名字：`getWeather`（清楚，查天气）

### 第二步 · 写一句描述

👈 AI 靠这句话判断"什么时候用这个工具"

- 坏描述："天气"
- 好描述："查询指定城市的当前天气。当用户问温度、会不会下雨时使用。"

### 第三步 · 说清楚要什么参数

👈 就像填表：姓名、电话、地址——缺一个填不了

- `getWeather` 需要：城市名
- `calculate` 需要：数学算式

> 🛑 **停一下！** 如果只给 AI 一个 `getWeather` 工具，描述写成"查询天气"，但用户问"上海到北京多远"——AI 会调用这个工具吗？为什么？

## 示范代码

给 Agent 装两个按钮 —— 一个查天气、一个算数。**重点看：** 工具是怎么被"注册"到 Agent 身上的。

```typescript
// ① 工具 = 名字 + 描述 + 参数（三个要素缺一不可）
const tools = [
  {
    name: "getWeather", // ① 名字：动词+名词
    // ② 描述：AI 靠这个判断"用不用"
    description:
      "查询指定城市的当前天气。" + "当用户问温度、会不会下雨时使用。",
    execute: async (params) => ({
      temp: 25,
      condition: "晴",
    }),
    // ③ 参数：要城市名
    parameters: { city: "string" },
  },
  {
    name: "calculate", // 第二个工具
    description: "计算数学表达式。需要精确结果时使用，不要让模型心算。",
    execute: async (params) => eval(params.expression as string),
    parameters: { expression: "string" },
  },
];

// ② 把工具列表交给 Agent —— 就像把遥控器递给 AI
const agent = createAgent({
  systemPrompt: "你是一个生活助手，会查天气和算数。",
  tools,
});

// ③ AI 自动判断用哪个按钮
await agent.run("北京今天热吗？"); // → 按 getWeather 按钮
await agent.run("3斤苹果每斤5块，一共？"); // → 按 calculate 按钮
```

> 🛑 **关键检查：** 上面 `getWeather` 的 execute 函数里，我们写死了返回 `{ temp: 25 }`。如果用户问"上海天气"和"北京天气"，返回的温度一样吗？—— 一样！因为 execute 没读参数里的城市名。**真正的工具实现里，你要用参数去查真实数据。** 这里只是示范结构。

---

## ⚠️ 常见错误（每个零基础学生都犯过）

- 错误 1：**工具名叫 `weather`** → AI 不知道是"查天气"还是"改天气"还是"删天气"。永远用动词开头。
- 错误 2：**描述写"天气工具"** → AI 看不懂。描述要写"什么时候用、干什么用"。
- 错误 3：**参数不写清楚是必填还是可选** → AI 会自己瞎猜。该必填就标必填。
- 错误 4：**execute 里不读参数** → 不管用户问哪个城市，你都返回北京的温度。记得读参数！
