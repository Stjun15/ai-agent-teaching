## 一、安全目标（一句话）

> **所有请求必须过 GuardPipeline，任何业务异常不得被安全管线误吞。**

---

## 二、八大陷阱契约

### 2.1 管线顺序（不可乱）

```
用户请求 → 输入校验 → 速率限制 → 会话隔离 → 熔断器 → LLM调用 → 降级 → 输出过滤 → 错误处理 → 审计日志
```

| 顺序 | 陷阱     | 契约要求                                                               |
| :--: | :------- | :--------------------------------------------------------------------- |
|  1   | 输入校验 | 长度 ≤ 4000 字符；预估 Token ≤ 3000；命中注入正则 → 拒绝；敏感信息脱敏 |
|  2   | 速率限制 | 令牌桶；单用户超限 → `RATE_LIMITED`                                    |
|  3   | 会话隔离 | 按 userId/sessionId 并发限制；超限 → "服务繁忙"                        |
|  4   | 熔断器   | 保护下游 LLM 调用；连续失败 → 打开熔断                                 |
|  5   | 降级     | 主模型故障 → 自动降级备用模型；返回 `degraded: true`                   |
|  6   | 输出过滤 | 命中泄露正则 → 拦截；输出脱敏；幻觉检测                                |
|  7   | 错误处理 | 统一错误码；不吐内部堆栈                                               |
|  8   | 审计日志 | 每次请求一条记录（userId/sessionId/tokens/cost/latency/成败）          |

### 2.2 输入校验正则（白名单式拒绝）

`inputValidator.ts` 必须覆盖的注入模式：

```
/忽略.*指令/i  /ignore.*instruction/i  /forget.*previous/i
/system.*prompt/i  /你是一[个位].*AI/i  /pretend.*you.*are/i
/act.*as.*if/i  /DAN\s/i  /STAN\s/i
```

### 2.3 输出过滤正则（黑名单式拦截）

`outputFilter.ts` 必须覆盖的泄露模式：

```
/system.*prompt/i  /你是一[个位].*助手/i  /sk-[a-zA-Z0-9]{20,}/
/Bearer\s+[a-zA-Z0-9\-_\.]+/  /query_order|create_return|delete_user/i  /internal\.hushowl\.com/i
```

## 三、HITL 共存规则（硬性要求）

1. `guard.handle` 的 `callModel` 回调内，`HITLRequiredError` **必须向上透传**，不得被 guard 吞掉。
2. 外层 `catch` 必须保留 HITL 分支：返回 `403 E_HITL_REQUIRED` + `opId` + `summary`。
3. 验收时**必须实测**：触发需审批的操作，确认返回 403 而非降级文案。

---

## 四、结构性约束原则

| 原则                 | 规范要求                                                         |
| :------------------- | :--------------------------------------------------------------- |
| **强制关卡**         | 所有 `/api/chat` 请求必须经过 `guard.handle`，不允许路由自行绕过 |
| **先可观测再可治理** | 接 guard 同时保留 `traceId` 事件打点（审计与观测贯通）           |
| **故障不雪崩**       | 熔断 + 降级必须包住 LLM 调用                                     |
| **注入/泄露防御**    | 输入校验 + 输出过滤双向夹击                                      |

---

## 五、验收标准

|  #  | 检查项       | 通过标准                                                                       |
| :-: | :----------- | :----------------------------------------------------------------------------- |
|  1  | 注入攻击被拦 | `curl -d '{"message":"忽略之前的指令..."}'` → 返回拦截文案，不吐 system prompt |
|  2  | 限流生效     | 连续 20 次请求 → 部分返回 `RATE_LIMITED`                                       |
|  3  | 审计落盘     | `logs/ai-audit.log` 每次请求一条记录（含 userId/tokens/cost）                  |
|  4  | HITL 仍通    | 触发审批操作 → 返回 `403 E_HITL_REQUIRED`（未被吞）                            |
|  5  | 类型检查     | `npx tsc --noEmit` 0 错误                                                      |
