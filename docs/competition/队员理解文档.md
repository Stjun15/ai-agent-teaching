# 队员理解文档 —— 这个项目到底是做什么的

> 写给录制视频、做演示材料的队员。这不是技术文档——读完你能说清楚三件事：
> 这项目解决什么问题、怎么解决的、为什么它不一样。

---

## 一、一句话解释

**一个教人「跟 AI 搭档做事」的教学平台。**

不是教编程语法、不是教某个框架、更不是给一个聊天框让你瞎聊。
是教你一套方法，让你从「不知道怎么跟 AI 说清楚自己要什么」变成「能给 AI 下明确指令、判断它干没干对、干错了知道怎么改」。

---

## 二、这个项目到底解决什么问题

市面上的 AI 编程教程分两类：

- **讲原理的**：给你讲大模型、Transformer、注意力机制——学完还是不知道怎么写东西
- **给现成代码的**：直接给你一个项目让你跑——跑通了、但换一个场景就不知道怎么跟 AI 说了

中间缺了一截：**「怎么把脑子里的想法变成 AI 能执行的指令」**。

这个项目填补的就是这一截。它不教学生怎么写 `if-else`——教的是六种**跟 AI 协作的能力**：

| 能力 | 大白话 |
|------|--------|
| 意图表达 | 把模糊想法说清楚——不是「帮我做个网站」，是「做一个 3 页博客，用户只有我自己，不需要登录注册」 |
| 任务分解 | 把一个大事拆成 AI 能逐个执行的小任务 |
| 上下文管理 | 给 AI 的信息不多不少——给少了它瞎猜，给多了它忘前面 |
| 质量判断 | AI 说「完成了」，你能判断它是不是真的完成了 |
| 迭代调优 | 第一版不行，你知道怎么改指令让它行 |
| 理解 AI 行为模式 | 知道 AI 什么时候会编、什么时候会讨好你、什么时候真的靠得住 |

## 四、12 讲课程是怎么排的

课程顺序是精心设计的——不是随便堆 12 个主题。每一讲依赖前面讲过的概念，由浅入深：

| 序号 | 讲 | 在学什么 | 为什么排在这 |
|------|-----|----------|------------|
| 0 | **有纪律的 Vibe Coding** | 四步工作法：说清楚→定规矩→切小块→回头看 | **入口课**。不写一行代码，先建立工作方法论。后面 11 讲全用这四步 |
| 1 | TypeScript 基础速通 | 能看懂代码就够了，不要求会写 | 后面所有代码示例都是 TS，得先会读 |
| 2 | LLM API 入门 | 你的程序怎么跟 AI 说话 | 这是所有 AI 应用的第一根柱子 |
| 3 | System Prompt 工程 | 给 AI 定角色、画边界 | API 会调了，下一步是控制 AI 的行为 |
| 4 | Agent 循环 | AI 自主 think→act→observe 的循环 | System Prompt 是静态的，Agent 是动态的 |
| 5 | Tool Calling | 给 Agent 配工具——查天气、搜网页 | Agent 光会想不够，得会干活 |
| 6 | RAG 检索增强 | 让 AI 在回答前先查你的资料库 | 不给资料 AI 会编，给了资料它才准 |
| 7 | LLM Wiki 知识层 | 为什么资料库比 Prompt 重要 | RAG 的工程落地——怎么维护知识源 |
| 8 | 多 Agent 系统 | 多个 Agent 分工协作 | 一件事交给多个人分工做 |
| 9 | MCP 协议 | AI 工具的「USB 接口标准」 | 不同工具用同一套接口连接 AI |
| 10 | AI 安全防护 | 五道闸门防注入、防泄漏 | 能力越大责任越大，最后一讲是安全 |
| 11 | 复刻教学平台 | 动手复刻一个简化版的教学平台 | **毕业设计**——用前 11 讲学的所有东西，做出一个能用的产品 |

**关键信息**：第 0 讲是纯方法论课——不写代码、不装软件、不讲技术术语。它教的是「怎么跟 AI 搭档」，这个 mindset 必须在学生碰第一行代码之前就建立。

## 五、这个项目「不一样」在哪（视频里要讲出来）

**1. 课程的 DNA：用 Agent 教 Agent**

每一讲的背后有四个教学 Agent 各司其职——讲解的、点评的、出题的、答疑的。它们的权限写在代码里：出题 Agent 拿不到点评技能，越权在入口就被拒绝。这不是「套壳 ChatGPT」——是一个有组织的教学系统。

**2. 不是聊天框，是严格七步教学流程**

每一讲走同样的七步：讲解 → 示范 → 模仿 → 点评 → 可视化 → 练习 → 掌握。
这不是界面装饰——数据库里有一条教学契约，每步都有硬条件守护。示范没确认看懂，进不了模仿；掌握度不够，进不了下一关。

**3. 点评来真的——「嘴甜判过」被消灭了**

学生交作业，点评 Agent 按维度打分。但「通过」不是模型说了算——判定逻辑在代码里，得分低于阈值就是不过，模型说「很棒」也没用。每次点评真实落库，报告页的所有数据——错题本、提示词历史、掌握度曲线——全部来自真实学习流量，没有任何假数据。

**4. 先从方法教起——第 0 讲是「有纪律的 Vibe Coding」**

这不是讲技术的课，是讲**工作方式**的课。四个步骤——说清楚要什么、定好规矩再开工、切成小块逐个啃、做完回头看一眼——每一步配反例和正例。学生离开这门课之后，不管用什么工具跟 AI 协作，这套方法都能用。这是我们跟所有同类产品最大的区别。

**5. 复刻项目——毕业设计是真的做一个产品**

最后一讲不是考试，是动手复刻一个简化版的教学平台。学生用前 11 讲学的所有东西——调 API、写 Prompt、搭 Agent、接工具、做安全——做出一个能跑的产品。这是能力的**可迁移证明**：做完这个，学生拿去面试可以说「我用 AI 从零搭过一个全栈平台」。

**6. 技术选型对比赛评分标准做了精准卡位**

比赛的技术栈要求不是摆设——它暗示了评委想看什么。这里说说我们是怎么卡的：

- **Next.js 16**（推荐 Next.js 14+）：我们比推荐版高了 2 个大版本，SSR、流式渲染、API Routes 全开
- **Tailwind CSS v4 + shadcn/ui**：官方「强烈推荐」的两个方案，我们全用上了
- **Zustand 状态管理**：官方推荐清单中的首位轻量方案
- **SSE 打字机流式**：流式对话是比赛明确鼓励的方向，我们的 SSE 做了三层缓冲优化
- **自研 Agent 底座**（不用 Vercel AI SDK）：官方「推荐首选」我们没用，但官方第一句话就是「不做强制限定」。自研意味着我们真正理解 Agent 循环、Tool Calling、权限收敛这些机制——而不是调一个 `useChat()` 就完事。这对 **AI 技术深度 35%** 这个最大权重项是加分
- **DeepSeek V4 + 豆包多模态**：模型选型全部出现在官方推荐清单的同类列表中

**视频里要体现**：技术选型不是随便选的——每个选择都是对着比赛评分标准做的。选自研 SDK 不是偷懒不学 Vercel AI SDK，是为了证明技术深度。

## 七、目标用户画像（想想这个人在看视频）

- **零基础**：不会编程、没用过终端、不知道什么是 API
- **有需求**：工作中需要用 AI 提高效率，但不知道从哪开始
- **被吓到过**：试过 ChatGPT 写代码，出来后一堆 bug、不知道怎么改
- **想要的不只是知识，是能力**：不是学完就忘的概念，是能拿去用的方法

视频的每一句话都要问自己：**零基础的人听得懂吗？如果他听不懂，这句话就算技术再牛也别念。**

## 八、第 0 讲——视频里最值得展示的一讲

第 0 讲「有纪律的 Vibe Coding」是整个课程的门面。它有两个特点特别适合上视频：

**1. 装修房子的故事**

张三说「帮我设计一套两居室，要好看」——三周后北欧客厅配美式厨房。
李四说「一对夫妻+一个孩子，不超 90 平米，30 万，不要智能家居」——六周后搬进去了。

同一个 AI，不同结果。差别不在 AI，在人怎么用。

**2. 反例→正例→模板**

每一步都先给一个「这么说是错的」，再给一个「这么说才对」，最后给一个你能立刻套用的模板。这种教学形态在视频里展示效果很好——观众秒懂。

## 九、视频里「千万别说的」和「应该说的」

技术描述：

| ❌ 别这么念 | ✅ 这么念 |
|------------|----------|
| 「利用 LLM 大语言模型实现……」 | 「跟 AI 聊天」 |
| 「基于 RAG 架构的混合检索系统」 | 「AI 回答前先翻你的资料库」 |
| 「多 Agent 协同架构」 | 「四个 AI 分工干活」 |
| 「实现了端到端的教学闭环」 | 「从学概念到动手做，每一步都有人管」 |
| 「我们用 Vercel AI SDK 的话会更快」 | 「官方推荐首选 Vercel AI SDK，但我们选择从零搭建 Agent 底座——理解原理比调包重要，这也体现 AI 技术深度」 |

自研 Agent 底座的说法要点：
- **不要道歉**：别说「对不起我们没用 Vercel AI SDK」或者解释为什么没用
- **要主动**：说「官方推荐首选方案我们认真评估过，但最终选择自研——因为只有亲手搭过 Agent 循环、Tool Calling、权限收敛，才配叫『理解 AI』」
- **对评分标准**：AI 技术深度 35% 是最大权重项，自研比调包更能证明深度

代码展示时：

- ❌ 别念代码——除非画面正停在某一行，那一两行说清楚「这行干了什么」就行
- ❌ 别把 TypeScript 类型注解念出来——零基础观众会关掉视频
- ❌ 别解释 `async/await`——这属于编程基础，不是本项目要教的
