# 演示视频脚本 —— 用 Agent 教 Agent（5-8 分钟）

> 官方要求：5-8 分钟 · MP4 ≥1080p · 普通话讲解（可配字幕）· 内容须含项目介绍、
> 核心功能演示、AI 技术亮点展示。本脚本按 **7 分钟**设计，弹性区间 6:00-7:30。
>
> **给录制者**：全文按分镜表顺次录，每镜独立录屏独立配音（便于重录）；
> 浏览器 1920×1080、缩放 100%；演示账号提前登好；每镜开头等界面完全加载。
> 「实拍口径」列是屏幕上要出现的关键信息，念稿时不必逐字。

## 分镜 1（0:00-0:45）项目介绍

**画面**：停在首页 3 秒 → 滚动到模块列表，扫过 12 讲。

**口播**：

> 想学 AI 协作的人，缺的不是教程，而是「从概念到能跑通的 Agent 项目」之间那条路：
> 怎么把想法变成 AI 能执行的指令、怎么判断 AI 是真会还是在编、错了怎么改。
> 这是「用 Agent 教 Agent」的编程教学助手——12 讲课程，从大模型 API 一路教到
> 多 Agent 系统与安全防护，毕业课题是复刻一个教学平台。它训练的是六项可迁移的
> AI 协作能力，而不是替学生写完代码。

**实拍口径**：首页标题、模块列表的 12 讲卡片、页面上的「六项能力」文案。

## 分镜 2（0:45-1:30）七步教学形态

**画面**：进入任一讲，展示七步导航条：讲解 → 示范 → 模仿 → 点评 → 可视化 → 练习 → 掌握。

**口播**：

> 每一讲都走同样的七步，这是数据库里的教学契约，不是界面装饰。学生看到的每个
> 环节，背后都有一个各司其职的教学 Agent：讲解、点评、出题、答疑四个 Agent
> 的权限写在代码里——出题 Agent 拿不到点评技能，越权在入口就被拒绝。

**实拍口径**：七步导航条逐个高亮；口播到「权限」时切一秒 `prompts` 代码页（可选）。

## 分镜 3（1:30-2:45）讲解 Agent：点开即有 + 带引用的追问

**画面**：点开「概念讲解」→ 讲稿即时出现（说明缓存命中）→ 在输入框提一个困惑 →
回答流式输出，回答上方出现「本节参考了哪几页」的引用。

**口播**：

> 讲解不是每次都等模型——每讲的讲稿预生成进缓存，点开即有。学生在讲解步
> 随时提问，回答逐字流式输出，而且先看到「本节参考了知识库哪几页」再看到答案。
> 检索是关键词加向量的混合方案：22 条真实学生问题实测，召回率从纯关键词的
> 77% 提升到 95%——这个数字是可以用一条命令复现的，不是口号。

**实拍口径**：讲稿秒出；引用条目（来源页名）；流式打字机效果；思维链默认展开的画面。

## 分镜 4（2:45-3:45）示范步与模仿步（分屏）

**画面**：示范卡展示带逐行中文注释的示范代码 → 点击确认 → 切到模仿步任务卡
「现在轮到你」→ Monaco 编辑器里写一段代码。

**口播**：

> 示范代码直接取自知识库，逐行中文注释，不经过模型——内容永远和教材一致。
> 确认看懂后才进入模仿步：任务卡明确交给学生，聊天按步骤过滤，示范和作业
> 不会串在一起。这是「教-示-仿」三步分离的分屏设计。

**实拍口径**：示范代码滚动一屏；确认按钮；模仿步任务卡与编辑器。

## 分镜 5（3:45-5:00）点评闭环与学情落地

**画面**：提交作业 → 点评 Agent 返回维度分、扣分问题、改进建议 → 切到报告页：
评分维度、错题本、提示词历史。

**口播**：

> 交作业的那一刻，点评 Agent 按维度打分，给出扣分问题和改进建议。通过线是
> 代码写死的硬条件——模型说「很棒」不算过，判定逻辑在代码里，从机制上消灭
> 「嘴甜判过」。每次点评真实落库：报告页的错题本、提示词历史、掌握度曲线
> 全部来自真实学习流量，没有任何假数据；兜底输出一律不写库。

**实拍口径**：点评结果的维度分与建议；报告页三块明细；「未计入掌握度」的兜底文案（如有）。

## 分镜 6（5:00-6:15）AI 技术亮点（三连）

**画面 A（5:00-5:25）**：播放一个可视化场景（推荐：检索-生成管线 或 攻击-防护对比）。

> 每个 AI 工程模块配一个可交互的可视化场景——Agent 怎么循环、检索管线怎么走、
> 提示注入怎么被拦，全部看得见。

**画面 B（5:25-5:55）**：在对话里拖入一张作业截图 → 视觉点评返回。

> 多模态入口：不会描述问题？截图就是提问。视觉模型走独立点评管线，
> 和文本点评同一套评分维度。

**画面 C（5:55-6:15）**：终端跑 `pnpm simulate:module` 的输出（或展示 12/12 全链路报告）。

> 这套课程的质量验证方式是它最大的不同：一个自动化的学生 Agent 替真人上课，
> 12 讲全链路模拟全部通过——课程质量从主观判断变成了可反复执行的命令。

**实拍口径**：场景播放的动态过程；截图上传后的点评结果；模拟命令的通过行。

## 分镜 7（6:15-7:00）收束

**画面**：学习路径调整卡片（掌握度下降 → 系统给出调整建议）→ 回到首页。

**口播**：

> 掌握度引擎按「只升不降」的练习语义与覆盖式测评更新学情，连续失败或错题
> 积压会触发学习路径调整——教什么、练什么，跟着学生走。这就是我们理解的
> AI Native 教育：AI 不只是内容的一个功能，而是教学判断本身。谢谢观看。

**实拍口径**：路径调整卡片的建议文案；首页结尾定格 3 秒（放作品名与口号）。
