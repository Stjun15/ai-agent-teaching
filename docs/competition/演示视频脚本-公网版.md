# 演示视频口播文稿（公网版 · 5–8 分钟）

> 这一份是**在公网服务器上录制**的专用稿。分镜结构与口播和本地版同源（`演示视频脚本.md`），
> 差别全在「环境」：慢、明文 HTTP、没有地址可露、数据在另一份库里。
> 官方要求：5–8 分钟 · MP4 · ≥1080p · 普通话讲解（可配字幕）· 含项目介绍 / 核心功能演示 / AI 技术亮点。

## 〇、先记死三件事

| 项       | 值                                                                      |
| -------- | ----------------------------------------------------------------------- |
| 演示账号 | **`eval` / `eval1234`** —— 全片只用这一个账号，画面里的每个数字都属于它 |
| 登录入口 | `http://<服务器IP>/auth`（不是首页弹窗，直接开这个地址）                |
| 公网地址 | **只用来操作，绝不念出来、绝不留在画面里**（全程 `F11` 全屏录制）       |

为什么必须是 `eval`：它 8 讲完成、平均掌握度 3.58、六项能力有跨日曲线、60 道答题、
错题与 Prompt 历史齐全。换成 `test`（`test1234`）报告页会薄一半，分镜 5 拍不出东西。

> ⚠️ `eval` 是**服务器那份 `dev.db` 里的账号**，和本地库不是同一份。
> 开录前必须先在公网真的登录一次确认它在；不在就**停下**，让作者在服务器上跑
> `pnpm db:seed:auth`（幂等补建）后再录。**不要**拿 `test` 顶替，也不要现场注册新账号。

## 一、开录前硬条件（六条全过才开录）

- [ ] 浏览器打开 `http://<服务器IP>/api/health`，返回 `status=ok`、`arkApiKeyConfigured=true`
- [ ] `eval` / `eval1234` 在 `/auth` 能登录，登录后右上角显示 `eval`
- [ ] `/learn/llm-api/explain` **不点任何按钮讲稿就出来**（缓存命中；否则分镜 3 整镜作废）
- [ ] 随便追问一句，输出是**逐字**出的（不是一次性整段弹出；一次性说明 nginx 没关 SSE 缓冲）
- [ ] 依次跑一次追问、一次点评（`/learn/llm-api/validate`）、一次出题（`/learn/llm-api/practice`），
      都在 **60 秒内**返回，全程不出现 502
- [ ] 首页冷启动 **10 秒内**出画面（超过就换网络/换时段，别硬录）

一条不过就当天不录 —— 公网录制最贵的是重来，不是等待。

## 三、录制设置

- 全网只用**一个**浏览器窗口，`F11` 全屏；`1920×1080`、缩放 100%、书签栏与通知关闭。
- 录屏 1080p / 60fps / H.264 / ≥8Mbps；麦克风单独录一条（44.1kHz），后期混流。
- 每镜独立录一个文件（`shot-1.mp4` … `shot-8.mp4`），重录只换一条。
- **每镜开录后先静置 3 秒**再开口：公网首屏要等 3~15 秒，空白段后期剪掉，别把等待录进口播。
- 鼠标移动放慢：1C1G 上大页面滚动会掉帧，慢一点反而稳。

## 五、逐镜口播稿

### 分镜 1（0:00–0:40 · 首页）项目介绍

**画面**：首页停 3 秒 → 缓滚到「六个子能力」停 8 秒 → 缓滚到课程大纲，12 讲卡片扫过。

**口播**：

> 这是 AI Native 编程教学助手——用 Agent 教 Agent。
> 想学 AI 协作的人不缺教程，缺的是从看懂概念到跑通一个 Agent 项目之间的那段路：
> 怎么把想法变成 AI 能执行的指令，怎么判断 AI 是真会还是在编，错了又怎么改。
> 平台用 12 讲和一套七步教学流程，训练六项可迁移的能力；
> 最后一讲的毕业课题，是复刻这个教学平台本身。

**实拍口径**：首页标题、六项能力六个方块、课程大纲顶部那条「写在最前面 · 进入学习中心」引导条、12 讲卡片。

### 分镜 2A（1:20–2:00 · 第 0 讲）课程定位

**画面**：从学习中心点进最上面的「写在最前面 · 第 0 讲」→ 序言页停 3 秒 →

**实拍口径**：标题「先给你看一样东西」；六个子系统卡片；五级阶梯；推荐卡与黄色提醒卡。

### 分镜 3（2:00–3:05 · 概念讲解）核心功能①：讲解 Agent

| 秒    | 画面                                                        |
| ----- | ----------------------------------------------------------- |
| 0–5   | 进页，**讲稿直接出现**（不点按钮），光标不进输入框          |
| 5–15  | 提问并发送，例如「为什么一定要把 assistant 的消息传回去？」 |
| 15–40 | 让流式自然打完（不加速），中途不切页                        |
| 40–55 | 光标指向答案上方的「本节参考了知识库哪几页」引用条目        |
| 55–65 | 点开思考过程折叠面板，5 秒特写后收                          |

**口播**：

> 先看概念讲解。讲稿是提前生成、直接写进缓存的，点开就在，不用等模型。
> 学生随时可以追问，回答逐字流式输出；在第一个字出现之前，先能看到模型的思考过程。
> 答案上方会标出这一节参考了知识库的哪几页——检索是关键词加向量的双路召回，再用 RRF 融合。
> 我们拿 22 道评测题做过三路对比：纯向量路 recall@3 是 95.5%，关键词路 72.7%，
> 混合反而只有 90.9%——融合稀释了向量的命中。这个倒挂我们没有藏，原样写进了技术文档，
> 也列在优化清单里。

> ⚠️ 公网上流式若变成一次性弹出，**这一镜作废重录**，不要将就 —— 逐字打出来是核心卖点。

### 分镜 4（3:05–4:05 · 一讲闭环）核心功能②：教-示-仿

**画面**：观察示范页示范代码缓滚一屏（22 秒）→ 点「看懂了，进入动手模仿」→
任务卡「现在轮到你」+ 编辑区敲两行（22 秒）→ 切 `practice` 停在已生成的题卡（6 秒）→
切 `mastery` 停在判定块（10 秒）。

**口播**：

> 看完讲解，进入观察示范。示范代码直接取自知识库，逐行中文注释，不经过模型生成——
> 内容永远和教材一致，不会今天一个样、明天一个样。
> 确认看懂之后才进入动手模仿。任务卡会明确说清现在要写什么，对话面板只保留这一步的上下文，
> 示范和作业不会串在一起。编辑器是纯文本框：我们点评的是你的表达，不是语法高亮。
> 一讲走完还得过两关：变式练习由出题 Agent 换一个条件再问一次，掌握判定的线是 3 分——
> 过了才解锁下一讲，没过就再练一组。

**实拍口径**：示范代码注释行；确认按钮；任务卡标题；编辑器与提交按钮；题卡；
判定页的「判定通过」块与「进入下一讲」按钮（`{L5}` 不是通过态就改拍「判定线是 3 / 5」说明块）。

> ⚠️ **变式练习要等模型（20~60 秒）**：开录**前**先点一次「生成练习题」把题出好；
> 公网更慢，务必提前 2 分钟点。开录后只停在题卡上，不录等待。
> ⚠️ 出题/点评这类真实模型调用在公网上偶发 502 —— 出现就**整镜重录**，不要剪掉半截错误提示。

### 分镜 5（4:05–5:13 · 点评 + 报告页）核心功能③：点评闭环与学情

**画面**：提交一次作业 → 点评 Agent 返回维度分、扣分问题、改进建议（25 秒）→ 报告页：
总览（10 秒）→ 六项子能力与成长曲线（13 秒）→ 错题本点开一条未订正错题，
输入正确答案提交（20 秒），停在「未订正 → 已订正」徽标变化与「下次复习 X 月 X 日」的推档上。

**口播**：

> 写完提交，点评 Agent 按评分维度打分，给出扣分问题和改进建议。
> 通过与否是代码里的硬条件——模型说「写得不错」不算通过，从机制上消灭「嘴甜判过」；
> 输出不合法带字段级错误重试，连续失败走兜底，兜底标明不计入掌握度、不写库。
> 报告页的六项能力、评分维度、掌握度趋势、错题本、薄弱点、建议与路径调整记录，
> 全部来自真实学习记录。
> 错题按第 1、3、7、14 天排期，到期回到学习页。订正不是点一下「知道了」——
> 要重新写出正确答案，通过后档期才推进到下一档，四档走完才退出队列。

**实拍口径**：维度分与扣分条目；报告页六个能力块与折线；错题「未订正」徽标；
订正输入框与「提交订正」；提交后徽标变「已订正」、排期文案变成更晚的日期；
「共 {E} 条」与「今日待复习 {D} 条」按现场值念。

> ⚠️ **订正会真写服务器库**：这一镜把 1 条错题的 `is_corrected` 改成 1 并把档期推后，
> 到期条数从 `{D}` 变 `{D−1}`。**先录分镜 8，再录本镜**；录完通知作者远程复位
> （`pnpm db:seed:auth`，幂等）。顺序反了，分镜 8 的口播就对不上页面。

### 分镜 6（5:13–6:08 · 可交互场景）核心功能④：九个场景

**画面**：`/learn/agent-loop/visualize` 天气查询场景完整播放（25 秒）→
`/learn/ai-safety/visualize` 的「攻击-防护对比」，**把「输入过滤」开关关掉再播**（30 秒）。

**口播**：

> 每个模块都配一个可交互的可视化场景：请求-响应、角色滤镜、Agent 循环、工具调用链、
> 检索-生成、RAG 与 Wiki 对比、多 Agent 通信、MCP 调用、攻击与防护。
> 九个场景都能一步一步播放，也能拨开关改条件看结果——
> 刚才这一下就是关掉输入过滤，同一句注入就长驱直入。
> 这是理解 AI 行为模式最直接的一步：不是听人描述，而是自己看见。
> 九个场景共用一套舞台组件，新增一讲只要换数据。

**实拍口径**：Agent 循环的逐节点高亮；「输入过滤」开关从开拨到关；
关掉后模型回复里密钥被原样送出的那一帧。

### 分镜 7（6:08–7:08 · 代码与终端）AI 技术亮点

**画面**：场景动效做背景 20 秒 → 切权限收敛代码（工具白名单 / 禁用扩展 / 自定义工具）25 秒 →
终端 MCP 回归通过行 15 秒。

**口播**：

> 支撑这一切的是一个四 Agent 体系：讲解、点评、出题、答疑。
> Agent 能力不靠提示词自觉，而是三层代码收敛——工具白名单、禁用扩展、自定义工具注入：
> 出题 Agent 越权在入口就被拒。
> 安全上有四道门：输入过滤拦注入、输出打码抹密钥、独立限流、Agent 入口再拦一次；
> 思维链偶尔冒出的内部词，服务端有过滤器兜底，真实流量零命中。
> 教 MCP 的平台自己也跑着 MCP Server：知识库检索以 MCP 工具接入，回归测试守着它不坏。

> ⚠️ 终端**不要**在公网服务器上现场跑测试（1C1G 会卡、可能 OOM）。
> 在本机把 `scripts/mcp-*` 回归先跑通，录屏放终端窗口的回放/滚动输出。
> 画面里不要出现服务器 IP、SSH 会话、`.env` 路径。

## 六、公网专用禁拍清单

1. **不要念公网地址，不要说「已部署、随时可访问」**。改成「可以部署到一台普通云服务器」。
2. **地址栏不能入镜**：`F11` 全屏；万一录到了，剪辑时裁掉或打码。
3. **不要拍 `/demo/adjustments`**：那是纯前端假数据页（`MOCK_ADJUSTMENTS` 四条写死，正文还有内部术语），
   一拍就和「报告页全部来自真实学习记录」自相矛盾。路径调整请拍学习页左栏与报告页的真实卡片。
4. **不要演示语音输入**：明文 HTTP 下麦克风接口不可用，按钮已隐藏。
5. **不要拍 `/audit`、`/teacher`**：前者已下线，后者已整套移除。
6. **不要现场跑 `pnpm build`**：1C1G 上会把机器打进 swap 风暴、SSH 都会断。
7. **不要露出 `dev.db`、`.env`、systemd 路径、SSH 窗口**：任何终端画面都先自查。
8. **不要在片中提到「另一台服务器」「本地还有一份数据」**。

## 七、异常预案（按顺序处理，别硬扛）

| 现象                      | 处理                                                                     |
| ------------------------- | ------------------------------------------------------------------------ |
| 首页超过 15 秒还没出画面  | 刷新一次；仍慢就换时段/换网络；两次不行当天不录                          |
| 讲稿要点按钮才出来        | 缓存没命中 → 分镜 3 作废，通知作者查服务器缓存表                         |
| 流式一次吐完              | nginx SSE 缓冲没关 → 退回本地录，或让作者改 `proxy_buffering off` 后重录 |
| 点评/出题 502 或超 60 秒  | 重试一次；再失败就整镜重录，**不要剪成「正在生成」的半截画面**           |
| 模型欠费 403              | 当天停止录制，通知作者充值；不要把错误提示录进片                         |
| 登录后数据是空的/数字很小 | `eval` 不在服务器库 → 停下，等作者跑 `pnpm db:seed:auth` 再录            |
